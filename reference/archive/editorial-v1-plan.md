# SehatFirstPro proposal implementation

## Direction
Warm editorial healthcare: ivory paper, forest ink, sage illustration fields, terracotta action color. Large serif headlines paired with a precise sans serif. Illustrations based on the three supplied prompt files, emphasizing the second prompt's organic lifestyle style. Original content and actual plan prices retained; no invented doctor counts, ratings, or trust statistics.

## Source map
- Aventura Dental Arts: oversized editorial hierarchy, service selector, strong section rhythm. https://aventuradentalarts.com/ — award status corroborated by agency awards list; visual inspiration, not an assertion that its proprietary React source is reusable.
- One Medical: plain-language care categories and membership navigation. https://www.onemedical.com/
- Ever/Body: treatment exploration and clear consultation CTA. https://everbody.com/
- React Bits: actual Magnet component source downloaded and adapted. See COMPONENT-SOURCES.md for source/license.
- 21st / Motion Primitives: magnetic interaction reference https://mcp.21st.dev/@ibelick/components/magnetic . Account-gated registry installs are not required because React Bits provides accessible source.
- Kelvin Adithya fun-isometric: actual canvas runtime, keyframe presets, React wrapper, and worked icons integrated.
- Local DVC: read its SmoothScroll.tsx and design documentation; reuse reduced-motion discipline and GSAP coordination.
- Local MJ: inspect Framer cursor markers; implement a restrained follower and magnetic controls with native cursor retained.

## Section plan
1. Slim utility line, wordmark/navigation, login choices.
2. Oversized editorial headline, illustrated healthcare garden, two clear journeys: explore plans / explore care.
3. Compact practical membership facts; no fabricated social proof.
4. Interactive service index: selectable rows, changing illustration/copy, contextual CTA.
5. Three-step membership journey with actual fun-isometric animation.
6. Plan finder: individual/family/senior filter, real six-plan data, benefit comparison and detail modal.
7. Full-width illustrated editorial care statement.
8. FAQ accordion, support CTA, functional footer and original policy links.

## Motion plan
- GSAP staggered hero entry; ScrollTrigger section reveals and illustration parallax.
- Actual React Bits magnetic wrapper for primary CTAs, capped movement.
- Cursor follower with contextual label on eligible pointer devices.
- Isometric stickers on real library keyframes, replay on hover, reduced-motion still frames.
- Service transitions, animated accordions, button arrow travel, nav underline, menu transition.
- Keep normal scrolling; no forced horizontal travel or hidden primary actions.

## Anti-pattern checklist
Avoid purple gradients, glass panels everywhere, repetitive three-card sections, generic AI dashboard art, excessive badge pills, fake metrics, every-element bounce, cursor-obscured text, inaccessible hover-only content, scroll hijacking, and overloaded animation libraries. Use varied section compositions and grounded healthcare copy.

## Plan review

Public portal redesign remains a visual extension and requires authorized accounts for post-login flows.
